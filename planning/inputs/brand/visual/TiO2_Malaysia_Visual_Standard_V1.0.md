# TiO₂ Malaysia Visual Standard V1.0

> 适用范围：第二个 Malaysia-origin TiO₂ 网站全站。  
> 后续 Codex、设计 Agent、图片生成、首页、内页、国家页、产品页都必须遵守这一套标准，除非后续明确升级到 V2。  
> 当前首页视觉稿仅作为 **Visual Direction Reference**，不代表最终首页内容架构。首页与其他页面内容必须等待关键词研究完成后再确定。

---

## 1. 品牌视觉定位

这个网站给人的第一感受应该是：

**Malaysia Origin + Industrial + International B2B + Technical + Trustworthy**

不是传统中国化工厂网站，也不是互联网 SaaS 网站，更不是廉价外贸模板。

客户进入网站之后，视觉上应该自然产生这样的判断：

> 这是一家真正做工业原材料国际供应的马来西亚企业，产品、原产地、出口和技术文件都是专业的。

运营主体：

**IKHLAS TITANIUM (MALAYSIA) SDN. BHD.**

但在视觉层级上：

> **前台网站品牌 > Malaysia Origin > 产品能力 > IKHLAS 企业主体背书**

IKHLAS 不需要抢网站品牌的位置。

---

## 2. 核心视觉关键词

| 维度 | 标准 |
|---|---|
| 品牌感觉 | Professional / Reliable / Technical |
| 行业感觉 | Industrial Materials / Chemical / TiO₂ |
| 地域感觉 | Malaysia Origin |
| 商业感觉 | International B2B |
| 网站感觉 | Clean / Modern / Premium |
| 信任感觉 | Compliance / Documentation / Traceability |
| 禁止方向 | 廉价、花哨、电商化、过度科技、传统化工模板 |

视觉必须保持**克制**。

不是通过大量动画、渐变和装饰让网站“高级”，而是通过：

**留白 + 字体层级 + 专业照片 + 深蓝 + 青绿 + 文档/数据元素**

建立高级感。

## 3. 主色系统

以后 UI 不允许每个页面自行发明颜色。

### 3.1 Primary Navy

**#062B5B**

用途：

- 标题
- 导航
- Footer
- 重要文字
- 深色背景

这是整个网站最主要的品牌颜色。

### 3.2 Deep Navy

**#031B3A**

用于：

- Hero 深色背景
- Footer 深层背景
- 特殊强调区域

不建议大面积使用纯黑。

### 3.3 Malaysia Teal

**#00A99D**

这是品牌第二识别色。

代表：

**Malaysia / international supply / modern manufacturing**

适用于：

- CTA
- Icon
- 重点词
- 链接
- 数据高亮
- 状态标记

### 3.4 Accent Teal

**#14B8A6**

用于：

- Hover
- 轻量渐变
- 图形辅助

不能比主蓝使用得更多。

### 3.5 White

**#FFFFFF**

网站主体背景仍然以白色为主。

### 3.6 Soft Background

**#F5F8FB**

用于不同 section 之间的轻微区隔。

不要使用明显灰色大块背景。

### 3.7 Border Gray

**#D9E2EC**

用于：

- Card 边框
- 表格
- 分隔线
- 输入框

### 3.8 Body Text

**#334155**

正文不要使用纯黑。

---

## 4. 色彩比例

全站大致保持：

- **白色：60–70%**
- **深蓝：15–20%**
- **蓝 / 青绿：10–15%**
- **灰色及其他辅助色：<10%**

青绿色是**品牌强调色**，不是背景主色。

不能把网站做成蓝绿色渐变网站。

渐变只允许用于：

- Logo
- Hero 局部装饰
- 少量 CTA
- 数据图形

## 5. Logo 标准

目前批准的 Logo 方向是：

> **TiO₂ + Malaysia + TiO₂ particle / orbit / Malaysia geographic identity**

Logo 由两个部分组成：

**Symbol + Wordmark**

Wordmark：

> **TiO₂**  
> **MALAYSIA**

Symbol 核心视觉元素：

**白色 TiO₂ 粒子 + 环绕轨道 + Malaysia 地理元素 + Navy / Teal**

它传递三个信息：

> TiO₂  
> Malaysia  
> Global supply

而不是单纯做一个抽象 Logo。

### 5.1 Logo 主版本

优先使用：

**横版 Symbol + TiO₂ MALAYSIA**

适用：

- Header
- Footer
- PDF
- 报价资料
- 邮件签名
- LinkedIn 等

Header Logo 建议实际显示宽度：

**170–210px**

不能为了“显眼”把 Logo 做得过大。

### 5.2 Logo 深色版本

深蓝背景情况下：

- Logo 中文字和辅助元素可以使用白色
- Symbol 蓝 / 青绿主体保持

### 5.3 Logo 禁止事项

不能：

- 拉伸
- 改变蓝绿配色
- 添加明显投影
- 添加外发光
- 使用彩虹渐变
- 放在非常复杂的照片上
- 擅自重新组合 Symbol 和文字
- 每个页面生成不同版本

Logo 必须逐步标准化为固定 SVG，而不是长期使用 AI 生成 PNG。

## 6. Icon / Favicon 标准

Icon 不使用完整的 `TiO₂ Malaysia` 字样。

使用 Logo 左侧的：

> **Particle Globe / Orbit Symbol**

也就是目前已经确定的独立图标方向。

它以后统一承担：

- favicon
- 手机 Bookmark
- PWA icon
- 社交媒体头像
- 浏览器 Tab
- 小尺寸品牌识别

### 6.1 小尺寸识别要求

Icon 必须在 **16×16 / 32×32** 这样的小尺寸下仍然能识别。

所以最终正式 Icon 应该比目前 AI 稿进一步**简化**。

小尺寸版本不要保留过多：

- 粒子
- 地图点阵
- 金属光泽
- 复杂高光

最终应该制作两套：

| 类型 | 用途 |
|---|---|
| Detail Icon | 256px 以上品牌展示 |
| Simplified Icon | favicon / 32–128px |

两套必须来自同一个图形语言。

## 7. 字体标准

英文网站字体建议统一采用：

### Primary Font

**Inter**

用于：

- Navigation
- Body
- Button
- Table
- Form
- 数字信息

### Heading

仍然可以使用 **Inter**，通过字重制造区别。

这样网页加载、SEO 和多设备兼容最好。

不建议为了“高级”再引入复杂的展示字体。

推荐字重：

| 内容 | Weight |
|---|---:|
| H1 | 700 |
| H2 | 700 |
| H3 | 600 |
| Navigation | 500–600 |
| Body | 400 |
| CTA | 600 |

---

## 8. 字号体系

桌面端参考：

| 元素 | 字号 |
|---|---:|
| Hero H1 | 52–64px |
| H2 | 36–44px |
| H3 | 24–30px |
| Card title | 18–22px |
| Body | 16–18px |
| Navigation | 14–16px |
| Supporting text | 14–16px |

手机版不简单机械缩小，而是重新调整排版。

正文行高保持大约：

**1.55–1.7**

工业 B2B 网站最忌讳文字挤在一起。

---

## 9. UI 卡片标准

当前视觉稿中的 Card 风格可以保留。

统一为：

**白底 + 浅边框 + 非常轻的 Shadow + 适度圆角**

建议：

`border-radius: 10–14px`

禁止做：

- 巨大圆角
- 玻璃拟态
- 强投影
- 霓虹边框

Card Hover 可以有轻微：

> 上移 2–4px + Border 强化

不要大幅浮动。

---

## 10. Button 标准

### Primary CTA

> **Teal Background + White Text**

例如：

**REQUEST A QUOTE**

### Secondary CTA

> White / Transparent + Navy Border

例如：

**VIEW PRODUCTS**

Button 圆角：

**6–8px**

不是圆形胶囊按钮。

因为这是工业 B2B 网站，不是消费 APP。

---

## 11. Iconography 标准

功能型 Icon 必须使用：

**简单线性图标**

例如：

- COO
- TDS
- SDS
- COA
- REACH
- Shipping
- Factory
- Technical Support

统一标准：

> **Navy outline + Teal accent**

禁止混用：

- 3D Icon
- emoji
- 彩色卡通图标
- 照片 Icon
- 不同图库风格

以后最好固定一套 Icon Library。

---

## 12. 图片视觉标准

网站图片必须属于下面四类：

| 类型 | 作用 |
|---|---|
| TiO₂ Material | 粉体、颗粒、材料性能 |
| Application | Paint / Plastic / Masterbatch / Ink 等 |
| Manufacturing | Malaysia factory / production |
| Global Supply | Port / container / shipping / market |

图片应该：

**真实、干净、工业化、国际化**

避免传统外贸网站大量出现：

- 握手
- 欧美商务人士微笑
- 客服戴耳机
- 假实验室人员
- 夸张化工厂烟囱

---

## 13. Malaysia 元素标准

Malaysia 是核心战略资产，但不能把网站做成旅游网站。

允许：

- Malaysia map
- Port Klang
- Manufacturing
- Malaysia flag 的小面积使用
- Kuala Lumpur skyline 作为辅助识别

不建议大量使用：

- Petronas Towers
- 沙滩
- 椰树
- 旅游景点

Malaysia 的视觉表达应该始终围绕：

> **Origin / Manufacturing / Export**

而不是 Tourism。

---

## 14. 国家市场视觉标准

当前战略市场：

- **European Union**
- **United Kingdom**
- **India**
- **Brazil**

国旗只作为识别辅助。

不能把页面设计成：

> 一面巨大国旗 + 一个国家名字

市场页面最终仍然必须延续 TiO₂ Malaysia 的品牌体系。

EU 可以用：

- EU flag
- industrial image
- logistics

UK、India、Brazil 同理。

---

## 15. 数据与文件视觉语言

这是这个网站非常值得强化的地方。

以下内容应该形成自己的：

> **Documentation Visual System**

包括：

- REACH
- COO
- TDS
- SDS
- COA
- Traceability
- Origin Documentation

以后这种内容优先使用：

- 线性文件 Icon
- 证书缩略图
- Data Card
- Verification Badge
- 表格

这样网站会比普通 TiO₂ 网站更有采购专业感。

---

## 16. 页面整体节奏

全站统一采用：

> **Wide Container + Strong Heading + Clear Sections + Large White Space**

建议内容最大宽度：

**1200–1320px**

不要做成文字铺满整个屏幕。

Desktop 网页正文两侧必须留出明显呼吸空间。

---

## 17. 动效标准

只允许轻量动效：

- Hover
- Fade
- 数字轻动画
- Navigation transition
- 轻微图片 Zoom

禁止：

- 粒子漫天飞
- 3D 地球自动旋转
- 大量视差
- 文字不停移动
- 复杂 loading 动画

动效是辅助，不是视觉主体。

---

## 18. 最重要的设计红线

以后不管 Codex 还是 Agent，只要出现下面这些方向，就应该直接判定为偏离视觉规范：

- **模板化中国化工网站**
- **过度科技蓝色炫光网站**
- **消费品电商网站**
- **SaaS Startup 网站**
- **廉价 Alibaba Supplier 页面**
- **过度使用 Malaysia 国旗和地标的旅游式网站**

我们的目标始终是：

> **Premium International Industrial B2B Supplier**

## 19. 当前 Logo / Icon / 视觉稿的地位

目前生成的 Logo、Icon、首页视觉稿不直接等于最终生产文件。

它们现在承担的是：

> **Visual Direction Reference**

也就是说，以下内容已经批准：

- 颜色
- 质感
- Logo 思路
- Icon 思路
- 卡片风格
- 图片风格
- 整体气质

以下内容**尚未批准**：

- 首页结构
- 首页文字
- Markets 顺序
- Products 顺序
- CTA 数量
- 页面内容结构

这些必须等待关键词研究。
