# TiO2 Atlas 首页样板设计

日期：2026-09-23
状态：已批准，首页样板已实现
范围：HOME-001 首页样板；其余页面的品牌迁移留待样板验收后分批设计。

## 目的与已确认决定

用户指出新 WordPress 网站与 [tio2malaysia.com](https://tio2malaysia.com/) 的页面、logo 和 icon 重合。新网站使用 tio2products.com 域名，前台品牌暂定 **TiO2 Atlas**，运营主体仍为 **IKHLAS TITANIUM (MALAYSIA) SDN. BHD.**。先交付可评审的首页样板，确认后再扩展全站。

样板成功的标准：访问者一眼能区分两个网站；logo、favicon、色彩、首屏图形、版式与首页文案形成独立识别；采购者仍能找到产品、应用、目的市场、文件和询价入口；不新增未经批准的产品、产地、合规、库存或交付主张。当前网站的 14 个型号和已核准事实继续作为内容依据。

现状审计：对照站首页与本地首页的标题、主要段落和导航版块相同；本地主题的 logo.svg、logo-reverse.svg 与对照站使用的同名品牌候选图形对应。现有 planning/inputs/brand/visual/TiO2_Malaysia_Visual_Standard_V1.0.md 适用于旧品牌，新方向由本设计在首页样板范围内取代。历史输入保留作来源证据，不就地改写。

## 视觉识别

方向：**Technical Atlas**。主背景为暖白 #F7F4EC，主文字与深色区为石墨灰 #202B2B，交互强调色为矿物橙 #9C3D22，辅助线与标签用中性灰。最终组合需通过 WCAG AA 对比度检查。避免旧站的深蓝、青绿、球体、环绕轨迹和马来西亚轮廓作为主识别。

Logo 为 “TiO2 Atlas” 字标加几何 A 标记。A 由坐标轴与晶格线形成，线条在 16×16 与 32×32 尺寸下简化；favicon 只使用简化 A。标记以仓库原生 SVG 绘制，提供浅色与深色背景版本。功能图标另建统一线性风格，不复制旧图标。

首屏主视觉采用原创的“材料与采购路径图”，表达产品组、应用、目的市场的入口关系。图中不使用数值轴，不暗示型号等效、性能或供应保证。现有粉体英雄图片不进入新首页。标题采用鲜明的编辑式层级，正文易读，型号和索引标签使用等宽字形。桌面采用偏移式左右布局，移动端按阅读顺序单列。

## 首页信息架构与文案边界

1. **首屏**：SEO 主题保留 “Malaysia titanium dioxide”；建议 H1 为 “Titanium dioxide products from Malaysia, mapped to your next decision.” 页面标题建议 “Titanium Dioxide Products from Malaysia | TiO2 Atlas”。主 CTA 进入产品目录，次 CTA 进入询价。
2. **从需求出发**：根据已知应用、型号或目的市场选择入口。以任务问题表达，而非复刻旧站的三个编号导航卡。
3. **14 型号目录**：按现有四个产品组展示全部 14 个型号及其已发布详情链接。只描述已核准分类，不作适用性或等效判断。
4. **采购资料**：将产品文件类型与询价所需信息并置，分别引导到文件页和 RFQ。文件可用性按现有页面的真实措辞表述。
5. **公司与来源**：明确 TiO2 Atlas 的运营主体，使用已核准的马来西亚来源和公司事实，并链接到 About。
6. **收束 CTA**：提示填写目的市场、应用、型号（如已知）、数量和所需文件后进入 RFQ。

首页不再重复旧站的长篇 FAQ 和资源摘要；完整内容仍可通过导航进入对应页面。整页文案重新撰写，事实性内容对照 Page Spec 和已批准资料逐项核对。SEO 描述、标题、H1 与可见文案同步更新，保留内部链接与 canonical 指向 tio2products.com。

## WordPress 边界与数据流

维持原生 WordPress。主题负责首页展示、新 SVG/logo、favicon、CSS 与响应式行为；tio2-products 插件继续负责产品数据、编辑行为和验证，不为品牌样板改动领域模型。

HOME-001 仍为可编辑 Page。新安装的初始化内容更新 data/pages/home.json；已有预览站通过限定 _tio2_owner 和稳定页面身份、核对预期旧内容的显式一次性迁移更新首页。重复运行无变化；若编辑者已改过内容，停止并报告冲突，不覆盖。首页样板只在独立 WordPress 预览运行，使用独立数据库写入；不触碰主预览数据库。

样板阶段以首页条件展示 Atlas 页眉、页脚和 favicon，其他页面维持当前品牌。后续全站推广时再把这些元素提升为全局共享组件，避免已完成页面在样板审阅前出现混合样式。样板不进行生产发布、不启用索引，也不触发外发邮件。

## 验收

- 视觉：1440、768、390 宽度检查首屏、目录、CTA、导航和页脚；无横向溢出。
- 可用性：链接目标 HTTP 200、焦点可见、键盘导航顺序合理、菜单与移动触控可用；A 标记在 favicon 小尺寸可辨认。
- 内容：14 型号与分类、运营主体、产地和文件措辞对照批准材料；对照站首页复核标题、主体段落、主要版式与图形已明显不同。
- 技术：PHP/内容/HTTP 回归；一次性迁移拒绝非本地站点并验证幂等、冲突保护与夹具恢复；SEO title、description、H1、canonical、noindex 预览状态检查。
- 输出：首页桌面与手机截图、验证记录和后续全站迁移清单，供用户评审。

## 风险与后续

“TiO2 Atlas”是当前设计选择。公开使用前另行核查商标和品牌使用风险；搜索初筛不能代替正式核查。首页样板验证后，按共同页眉页脚、Hub、市场/应用/产品、文件/资源、表单/法律文案的依赖关系安排全站迁移。全站改名涉及 SEO 与通知邮件文案，需要单独审查；生产发布仍按仓库流程取得明确授权。
